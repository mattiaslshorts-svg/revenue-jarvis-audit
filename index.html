Revenue Jarvis

Private desktop operation. Human Founder Review. YouTube API Services.

Local content, human decisions

Revenue Jarvis is Mattias Larsson's single-user Windows application for managing locally produced content for ToolRush and Carl's Exit Liquidity. Local quality, rights and compliance checks precede human Founder Review.

Channel-safe private upload

The YouTube integration uses Google OAuth, exact channel identity checks and a video hash bound to the reviewed metadata. Optional private upload automation uses private visibility and does not schedule public release. PUBLIC is blocked; the current installation is DRY_RUN with uploads disabled.

You control YouTube access

The desktop application includes REVOKE YOUTUBE ACCESS and DELETE STORED YOUTUBE API DATA, each requiring confirmation for the selected profile. Local data deletion does not delete content stored by YouTube. Periodic authorization checks and API-cache deletion are scheduled every 29 days while the runtime is running.
