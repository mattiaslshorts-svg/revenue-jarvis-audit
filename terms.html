Revenue Jarvis Terms

Effective date: 2026-10-01. Operator: Mattias Larsson. Contact: https://github.com/mattiaslshorts-svg/revenue-jarvis-audit/issues

Scope

Revenue Jarvis is a private, local, single-user desktop tool for the operator's own content channels. It is not a public SaaS service, does not onboard third-party channels and makes no claim of YouTube endorsement or completed API audit approval.

YouTube API Services

Revenue Jarvis uses YouTube API Services. By using the YouTube integration, you agree to be bound by the YouTube Terms of Service at https://www.youtube.com/t/terms . Google handles sign-in and its own data under https://policies.google.com/privacy . Read our Privacy Policy at https://mattiaslshorts-svg.github.io/revenue-jarvis-audit/privacy.html .

Operator responsibility

The operator must hold rights to source material, verify facts and disclosures, review each candidate and comply with YouTube rules. Founder approval binds the exact local video hash, channel and metadata. Approval does not bypass runtime safeguards or permit public publication.

Current publication limits

PUBLIC remains restricted. The installation is currently DRY_RUN; private upload automation is separately opt-in and currently disabled. An enabled private workflow uploads only approved content to its bound channel as private, without scheduling public release. Use YouTube Studio at https://studio.youtube.com/ for YouTube-side management. These limits are imposed by this application.

Consent, deletion and maintenance

The operator may revoke Google access or delete managed local YouTube API data using the confirmed controls in the desktop application. Local deletion does not delete videos on YouTube. Maintain the local runtime so its 29-day checks can run, or delete cached API data before extended inactivity. The Privacy Policy describes cache deletion, invalid-authorization handling, exports and local-machine limits.

Analytics permission

YouTube-derived metrics are disabled unless separately approved by Google and explicitly enabled with matching evidence. Submitting an audit form does not grant permission. No financial performance, audience growth or uninterrupted API availability is promised.
