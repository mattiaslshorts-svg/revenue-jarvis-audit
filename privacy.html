Revenue Jarvis Privacy Policy

Effective date: 2026-10-01. Operator: Mattias Larsson. Public contact: https://github.com/mattiaslshorts-svg/revenue-jarvis-audit/issues

A private, local application

Revenue Jarvis is a single-user Windows desktop application used by its owner for the owner's channels. It uses YouTube API Services and Google OAuth. It is not a public hosted service and does not onboard third-party channel owners.

Data and purpose

Google handles account sign-in and consent. The application stores OAuth access/refresh credentials locally and uses channel identity, video IDs, metadata and status to bind approved work to the correct channel and verify private uploads. Optional YouTube analytics, statistics and search ranking are currently disabled pending separate derived-metric permission. Local scripts, source videos, original assets, rights evidence and Founder decisions are authored production records, not downloaded YouTube media.

Storage and sharing

Application data is stored in local SQLite databases and JSON files. Token files are local files protected by the Windows account; they are not application-encrypted. Approved video files and publication metadata are sent to YouTube only through an explicitly enabled, channel-bound private upload workflow. Google processes information under https://policies.google.com/privacy . Revenue Jarvis does not sell YouTube API Data and does not provide it to advertisers or third-party analytics services.

Private uploads and public restriction

A human Founder reviews the exact video and publication metadata. Private upload requires separate runtime activation and channel/credential verification. The current installation is DRY_RUN, with private automation disabled and PUBLIC blocked. This is an application safety restriction, not a YouTube restriction. YouTube-hosted content can be managed directly at https://studio.youtube.com/ .

Retention and authorization checks

While the local runtime is running, an hourly GUI check and existing auto-controller cycles dispatch compliance maintenance. Each profile has a persisted authorization check, next required check and cache-deletion status. Checks are scheduled every 29 days, providing a margin before 30 days. Before API use, overdue or unverified profiles are blocked. The routine verifies OAuth and the exact bound channel, then deletes managed cached API metadata and statistics instead of retaining historical copies. Deleting the caches also removes records of remote resources that may no longer exist.

Local deletion

Choose the profile and DELETE STORED YOUTUBE API DATA, then confirm. The application disables API access and deletes managed channel/video API metadata, remote status/readbacks, analytics/statistics, search results and inventoried API exports for that profile. It preserves local source videos, scripts, original assets, rights evidence, operator-configured channel routing and local job/hash reservations that prevent duplicate uploads. A minimal action record stores time, profile, categories and result. Deleting local Revenue Jarvis API data does NOT delete content stored by YouTube.

Revoke access

Choose REVOKE YOUTUBE ACCESS and confirm. The application immediately attempts Google token revocation, blocks further API access, marks acknowledged revocation REVOKED, removes the local token and deletes the managed API data. If Google cannot be reached, REVOKE_PENDING blocks access and local deletion still runs; retry the action or revoke externally. Google may revoke other tokens belonging to the same Google-account/client grant. You can also revoke access at https://security.google.com/settings/security/permissions .

Invalid authorization and deletion timing

An unrefreshable token, an API authorization rejection or a failed identity check disables access and starts deletion immediately. The implementation uses immediate deletion rather than waiting for the policy limits: seven calendar days after an in-app request and thirty calendar days after external revocation. Failed local deletion remains blocked and is retried by maintenance, with the deadline recorded. External-revocation deadlines are conservatively anchored to the last successful authorization check.

When the computer is off

This is a local application, not an always-on cloud service. It cannot run while Windows is off, asleep or the runtime is closed. Keep the runtime running for periodic maintenance, or delete stored API data before extended inactivity. On restart, overdue authorization remains blocked and deletion is attempted before renewed access. Copies manually exported or backed up outside the managed application inventory must also be removed by the operator; do not restore deleted API data from backups.

Derived metrics

YOUTUBE_DERIVED_METRICS_APPROVED defaults to false. YouTube-based custom scores, engagement/velocity ratios, net follower calculations, revenue deltas and downstream optimization are disabled. Audit submission is not approval. Enabling these optional calculations requires an explicit configuration change and separate Google approval evidence bound to its file hash and this API project. Non-YouTube local analytics are unaffected.
